# GARVEL / ГАРВЕЛЬ — финальная статическая сборка

Основа: предоставленный GARVEL_site_v7_preview.zip. В архиве пользователя не было версии v8; сохранены дизайн, структура, наименования и основные тексты доступной версии.

Сайт содержит главную страницу и каталог: 6 направлений, 73 карточки. Для всех карточек подготовлены отдельные фотореалистичные концептуальные визуализации. Они не являются фотографиями готовой продукции, подтверждением ассортимента или точными изображениями согласованных моделей. Для общих позиций «мебель по чертежам» и «комплект по ТЗ» показаны примеры возможных решений; окончательная конструкция определяется проектом.

## Размещение на GitHub Pages

1. Загрузите содержимое этой папки в корень выбранной ветки репозитория: index.html, catalog.html, assets/ и .nojekyll.
2. Выберите эту ветку и папку корня в настройках GitHub Pages.
3. Сборка и установка зависимостей не нужны. Относительные пути поддерживают размещение в подпапке репозитория.

Сайт также открывается локально через index.html. Кнопки запроса и копирования КП удалены по решению владельца. Связь с заказчиками будет осуществляться напрямую по телефону или электронной почте после добавления контактов.

## Изображения и проверка

- assets/visualizations/ — 73 отдельных изображения WebP, без повторного использования файлов в карточках.
- IMAGE_PROMPTS.json — исходные запросы к встроенному ImageGen и привязка к позициям.
- VALIDATION.md — результаты проверки структуры, ресурсов, уникальности, навигации и адаптивности.
- Интерьерные изображения из исходного архива сохранены как общий визуальный материал, без заявления о реализованных проектах GARVEL.
- assets/interior.jpg — сохранённое локально исходное интерьерное изображение Unsplash: https://images.unsplash.com/photo-1600210492486-724fe5c67fb0 .

## Ограничения исходных данных

В предоставленном архиве раздел «Контакты» не содержит телефона, электронной почты и реквизитов. Они не выдуманы; заказчики будут связываться напрямую по телефону или электронной почте после добавления контактов.

Фраза исходного текста о соответствии «всем международным стандартам» подтверждена владельцем и сохранена. Заявления о собственном производстве не добавлялись.
